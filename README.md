# Arkham Carcosa: low-fidelity prototype

A non-functional HTML gameplay prototype for a WebGL tabletop adaptation of a card game.
It explores the "two focuses" UX: the shared table versus the player's own area.

Open `index.html` in a browser. It needs no build step. Three.js and GSAP load from cdnjs.

All art is procedural. The prototype contains no official card art.
